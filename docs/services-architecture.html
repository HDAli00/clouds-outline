Outline – Service Architecture

Monorepo service decomposition & infrastructure topology

Deployment Configuration (Procfile)

In production, services are grouped into two process types. The web process handles all client-facing traffic, while the worker process handles background jobs. Each can be scaled independently. 

web:    yarn start --services=web,websockets,collaboration
worker: yarn start --services=worker

Inter-Service Communication
From To Protocol Purpose
Client Web HTTP API calls, page loads, authentication
Client WebSockets WebSocket Real-time events, notifications, presence
Client Collaboration WebSocket Document CRDT sync (Y.js protocol)
Web Worker Queue Async event dispatch (globalEventQueue)
Worker WebSockets Redis Push events to connected clients (websocketQueue)
WebSockets WebSockets (N) Redis Pub/sub for multi-instance fan-out
Collaboration Collaboration (N) Redis CRDT awareness across instances
Cron Worker Queue Schedule CronTask jobs on taskQueue
